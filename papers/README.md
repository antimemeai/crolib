# Literature

- Brennan, Robert L. (2001). *Generalizability Theory*. Springer.
  https://doi.org/10.1007/978-1-4757-3456-0
  Multifacet universes of generalization and D-study designs anchor the first
  release. Later chapters cover uncertainty, unbalanced, and multivariate work.
- GENOVA suite, University of Iowa:
  https://education.uiowa.edu/casma/computer-programs
  Balanced univariate, unbalanced random-effects, and multivariate reference
  programs; study and reproduce their examples before extending design support.
- Smith, Kline, and Kline. *GeneralizIT: A Python Solution for Generalizability
  Theory Computations*. https://arxiv.org/abs/2411.17880
  Read the versioned paper separately from current package documentation.

Keep PDFs ignored. Record exact versions and provenance when acquiring sources.
